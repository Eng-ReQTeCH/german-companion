# Wort — German course companion

A personal study app for your first German course. Includes weekly notebooks, vocabulary with English and/or Arabic meanings, bulk entry, German speech, scheduled flashcard reviews, lesson filters, ready-to-study Anki decks, and JSON backups.

## Run on this machine

Install Node.js 22.13 or newer, then run:

```sh
npm start
```

Open http://localhost:3000. There are no npm dependencies or build step. `data/study.json` is created automatically. Initial material is explicitly labeled as starter examples, not your actual course.

## Run on your home server

Copy this folder to the server, excluding `.agents`, `data`, and `test-results`. With Docker Engine and the Compose plugin installed on the server:

```sh
docker compose up -d --build
```

Open `http://YOUR-SERVER-IP:3000`. The named `wort-data` volume persists words, lessons and reviews across container rebuilds. The container runs as a non-root user and includes a health check. Docker is not required on your current computer.

To update, copy the changed source files and run the same command again. `docker compose down` preserves your volume; **do not use `down -v`** unless you intend to delete all data. Back up regularly using the app's Backups & settings page. To migrate to another server, download a backup, start the new container and restore the JSON file.

This is a single-user app without authentication. Use your trusted LAN or VPN. For public access, place it behind a reverse proxy with HTTPS and authentication. No external fonts, analytics, APIs or online learning services are required. Pronunciation uses the dedicated German Piper voice service described below.

Optional configuration: `PORT` (default `3000`), `DATA_DIR` (default `data`), `TTS_URL` (default `http://127.0.0.1:5002/synthesize`). Run one app instance per data directory. Storage writes are serialized and atomically replace the JSON file. Corrupted data fails startup instead of silently resetting your notebook.

## German pronunciation

Listen buttons play WAV audio generated by **Piper with de_DE-thorsten-high**, not Windows/browser speech. Docker Compose builds and starts the dedicated voice service automatically; it is accessible only inside the Docker network. The model is downloaded at image build time. Once built, pronunciation runs on your server CPU without accounts or external API requests. Generated audio is cached under the app data volume and regenerated when a word changes.

For development without Docker, use Python 3.12 or compatible with `piper-tts`:

```sh
python -m venv .venv-tts
# Activate the environment, then:
pip install -r tts/requirements.txt
python tts/download_voice.py
python tts/server.py
```

Keep the voice process running alongside `npm start`. If unavailable, the app reports a playback error and never falls back to device speech. Phrases up to 300 characters are supported. The first generation can take a few seconds; subsequent plays use the cached audio. Audio cache files are not included in JSON backups, since they can be regenerated.

Voice sources: [Piper Python API](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/API_PYTHON.md), [Thorsten voice model and license](https://huggingface.co/rhasspy/piper-voices/blob/v1.0.0/de/de_DE/thorsten/high/MODEL_CARD). Piper is GPL-3.0; the voice license is included with the downloaded model.

## Your weekly workflow

1. Share the week's course notes in our chat. We can add explanations, examples and exercises to the app as the course progresses.
2. In Course notebook, add or edit a week, including its date and your class notes.
3. Click **Add a word**, type the German and press Enter. Week 1 vocabulary fills in English and Arabic automatically, including articles for known nouns. Unknown words are captured immediately without invented meanings. Add meanings directly in the collection; Enter or leaving the field saves them. Language and reading direction are persistent controls on the word-list page and are also used as the initial practice/export preferences. Words missing a meaning in the selected language are excluded from review/export until you fill it in. Optional details remain available separately. Bulk paste from spreadsheets or `German | English | Arabic` is also supported.
4. Practice due words or all words, in either direction, optionally filtered by lesson. Again schedules a review in 10 minutes; Got it and Easy advance through 1, 3, 7, 14, 30 and 60 day intervals. These are simple study intervals, not Anki's scheduling algorithm.
5. In Anki studio, select direction, meaning language and lesson. Download `.apkg` and open it in Anki. Both directions produces two cards per word. The text option uses UTF-8 with Anki file headers; import it using the Basic note type and Front/Back fields. Missing translations in the selected language are skipped.

Anki packages use a legacy-compatible SQLite collection and ZIP archive. Notes have stable identifiers per word, language and direction so re-exporting the same collection can update existing notes. Examples are included on the answer side, Arabic uses automatic direction, and card HTML is escaped. Export format references: [Anki text import documentation](https://docs.ankiweb.net/importing/text-files.html) and [genanki package schema](https://github.com/kerrickstaley/genanki/blob/main/genanki/apkg_schema.py).

## Week 1 and irregular verbs

Week 1 includes the alphabet with letter names/IPA, umlauts, common sound groups, 1–20 and compound numbers, a 0–9999 number builder, colors, an introduction builder, regular present-tense endings and irregular examples. Topics open individually; study progress persists on the server. Twelve knowledge checks give explanations and allow retries. Listening examples use the same Piper voice as vocabulary playback.

The **Irregular verbs** page stores six present-tense forms: ich, du, er/sie/es, wir, ihr, sie/Sie. You can save/edit/delete custom verbs, start from the sein/haben/sprechen references, open a conjugation from any word row, and practice all six forms. Meanings entered for a saved custom verb are reused when you add it to vocabulary. The references are examples, not a claim about which irregular verbs your teacher covered. Strong verbs may be irregular in other tenses despite regular present-tense forms; the notebook records the present tense only.

Existing notebooks migrate automatically. An untouched starter lesson becomes Week 1; customized notes are preserved and receive a separate Week 1 lesson. A pre-migration JSON copy is saved in `data/before-week-1.json`. Verbs and topic progress are included in backups; older backups without them can still be restored.

## Verification

```sh
npm test
npm run check
```

Tests cover validation, bilingual exports, multiline/tab safety, package structure, SQLite integrity, server persistence, reviews, restore and cross-origin protection. Browser QA covers vocabulary create/edit/delete, Arabic search, card review, APKG download and desktop/mobile layout. `scripts/browser-check.mjs` uses the development machine's bundled Playwright runtime and Chrome; it is not a runtime dependency and may need local path changes on another machine.

Docker build/run and import in the Anki desktop application were not tested on this computer. The generated package's structure and SQLite contents were tested. See `REVIEW.md` for the judge assessment and its limits.
